FortiGate log triage

Runs entirely in this browser tab. Files are never uploaded.

Drop FortiGate logs anywhere on this page

Or use Open log files. Parsing happens in this tab, and the page blocks all network requests, so customer data stays on this machine.

Reads
Format is detected line by line, so mixed files are fine: FortiGate key=value (syslog captures, GUI download), quoted CSV exports in the FortiAnalyzer style ("key=value","key=""value"""), FortiGate CEF, and .gz files.
Time
Uses eventtime (UTC epoch) when present, otherwise date + time + tz. Lines with no time zone are treated as UTC and flagged.
Limits
Everything is held in memory. A few hundred MB is fine in a desktop browser. Past 1.5 million events the rest are skipped and counted.

Firewall in these logs

Model is read from the serial number prefix in devid. Lines marked inferred are reasoning, not fact.

field=valueExact match, case-insensitive. Commas mean any of: action=deny,blocked
field!=valueExclude. -field=value does the same.
field~textField contains text: url~login
field>n, field<nNumeric compare: sentbyte>100000000
srcip=10.0.0.0/8CIDR match on IPv4 values. Wildcards work too: user=svc_*
ip= port= host= country=Shortcuts that check source and destination fields together. ip= also checks remip.
file=Source file name: file="export 01.csv"
source=A log source by its id from the source cards: source=S2, or source!=S2 to exclude it.
kind= verdict=kind=utm/ips is type/subtype. verdict= is allowed, blocked or other.
"some text"Searches the whole raw line. -word drops lines containing it.
Every term must match. Press Enter to apply.
